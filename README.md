# Research Methodology Revision Hub — Exam Preparation Edition

## Run locally
1. Extract the ZIP to a folder.
2. Open `index.html` in a modern browser.
3. Internet is only needed for optional Google Fonts and the external NPTEL link.

## Included
- Cream/paper-like study dashboard inspired by the supplied reference screenshots
- 12 study modules with expanded first-time learning notes, examples, key facts and self-checks
- Colorful study-point cards in each week, with six alternating pastel tones
- Separate interactive flashcards with week filters and local mastery tracking
- One combined Practice Quiz containing 120 assignment questions across Weeks 1–12, with multi-select support where multiple answers apply
- Assignment screenshots from the original archive, plus the three newly supplied Week 10 screenshots; prior Week 10 folder images are preserved separately as legacy files
- Uploaded transcript and textbook extracted text files, plus structured study notes and assignment question JSON
- Local progress tracking

## Important source note

The website has not been deployed to a public URL.
